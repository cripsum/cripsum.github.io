# Icone degli archetipi del Rewind

Un PNG per archetipo, con il nome esatto dell'archetipo:

    nottambulo.png     collezionista.png   sociale.png
    competitivo.png    architetto.png      completista.png
    creatore.png       maratoneta.png      fantasma.png
    esploratore.png

Consigliato: quadrate, almeno 512x512, sfondo trasparente. Vengono mostrate
dentro un riquadro arrotondato al 76% della sua dimensione.

Se un file manca, resta l'icona vettoriale gia' configurata in
`rewind_persona_catalogue()` (includes/rewind_helpers.php): non serve
caricarle tutte insieme.
